Walk on satellite photos

See the real place from above, trees, cars and all. The photos come from a map company and need a key, which you can get for free:

  • Esri: sign up at ArcGIS Location Platform (no card needed) and create an API key with access to basemaps. 2 million photo tiles a month are free.
  • Google: in Google Cloud, turn on the Map Tiles API and create an API key. Needs a billing account; 100,000 tiles a month are free.

Your key stays in this browser. In the service's settings, limit it to this website so nobody else can use it.
